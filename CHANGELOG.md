# Changelog

## 0.2.0 — 2026-10-03

- Compact navigation for Dictation, History and Settings in the same window.
- Last 30 completed messages in memory, with timestamps, refinement mode, full preview, recopy and clear.
- Processing indicator and clearer action availability in the window and tray.
- History access from the tray and independent handling of notification failures.
- Session history clears on Quit and never enters logs or notification text.
- Updated English guides and interface illustrations.

## 0.1.0 — 2026-10-03

First published Windows version, created to make everyday messaging easier after a broken arm.

- Local Whisper dictation with automatic GPU selection and cached model preparation.
- Optional Codex CLI refinement with a built-in writing style and CLI readiness checks.
- One embedded Settings page, separate recording/paste shortcut captures and live application.
- Manual Ctrl + V macro for keyboard/mouse accessibility.
- Recording/completion sound cues, Windows tray status and stage notifications.
- Cancellation, retry, bounded shutdown and cleanup of the tray, inputs and GPU process.
- English setup, architecture, troubleshooting and validation documentation.
- Automated Windows tests, lint and package resource checks.
